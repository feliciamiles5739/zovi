# Zovi — one-page shop (zovi.com)

One file, `index.html`, and nothing else. Upload it to the root of **zovi.com** and the shop is live.

- Catalogue, add-to-basket, quantities, running total and the order form are all inside the file (no build, no dependencies).
- Product photographs are served from the shop CDN (`shop-cdn.misc-e60a.workers.dev/zovi/`) — the same photos the full site used; credits at the foot of the page.
- Orders are emailed to **orders@zovi.com** through FormSubmit. Nothing is charged on the site.
- Before launch: create the mailbox in cPanel, send the form once, and click FormSubmit's activation email.
